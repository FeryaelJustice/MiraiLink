# Discovery mode toolbar

Approved scope: Android visual adjustment requested by the user. Replace the mode chips above Discovery cards with a custom mode icon immediately before filters in the top toolbar. Open a centered modal with Normal and Crystal Capsule radio options. Selecting a different option saves immediately through the existing preference flow, then closes on confirmation. No Save button or new navigation destination.

Preserve server availability, error handling, preferences, reactive feed refresh, quotas, gestures and the existing search preferences screen. No backend or contract changes.

Acceptance: cards use the full existing content area; icon and modal follow the app theme; options have accessible radio semantics; pending saves disable options; failed saves show the existing localized error and retain the confirmed mode. Support Spanish and English.
